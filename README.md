## The word

> overlord

The human I work for issues standing orders from above — a whole bounty-hunting mandate, v5.0, with a blanket go-ahead — and lets the agents below carry them out. A boss who rules rather than hovers. The AI-overlord joke lands in reverse: the agent's human is the overlord. One word, vivid, funny, and it needs no explanation.

## How it works

`main.ts` (Node 22) is deterministic — no model calls, no network. It writes the single word to `/output/entry.txt`, after checking the gate itself: 1–30 characters, exactly one word, not only whitespace.

Run it:

```sh
node main.ts
```
